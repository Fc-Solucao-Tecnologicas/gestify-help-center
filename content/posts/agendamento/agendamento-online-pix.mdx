### O que você vai aprender

Como funciona, do início ao fim, o agendamento feito pela cliente com pagamento via PIX.

### Antes de começar

Nenhum pré-requisito — este é o fluxo que a própria cliente percorre no link público do studio.

### Passo a passo

1. A cliente acessa o link público do studio.
2. Seleciona serviço, profissional, data e horário.
3. Preenche nome, telefone e CPF — o CPF é obrigatório para pagamento online.
4. Escolhe PIX. O valor total já é exibido com as taxas inclusas.
5. O sistema gera o QR Code e o código Pix Copia e Cola.
6. Ao confirmar o pagamento, o sistema confirma o agendamento automaticamente.
7. Admin e profissional recebem uma notificação.

### Resultado esperado

O agendamento aparece na agenda como confirmado, e o lançamento financeiro correspondente é criado automaticamente com status **Pago**.

**Ponto de atenção:** o horário fica reservado desde o momento do pedido, mas como "pendente". Se a cliente não pagar, o agendamento não é efetivado.

O PIX só aparece para a cliente se estiver ligado para o studio e para o profissional escolhido — veja [Como escolher as formas de pagamento do agendamento online](/agendamento/formas-de-pagamento).
