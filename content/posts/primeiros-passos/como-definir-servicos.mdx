### O que você vai aprender

Como cadastrar um serviço (corte, coloração, manicure, ou qualquer outro atendimento que seu studio ofereça).

### Antes de começar

Você precisa ter o perfil **Admin**. É recomendável já ter pelo menos um profissional cadastrado.

### Passo a passo

1. Acesse **Organização → Serviços → Novo Serviço** no menu lateral.
2. Preencha o nome do serviço — é isso que a cliente vê no wizard de agendamento.
3. Adicione uma descrição, se quiser detalhar o que está incluso.
4. Informe a **duração em minutos** (mínimo 1, máximo 480). Esse campo é crítico: ele controla diretamente quais horários ficam disponíveis para agendamento.
5. Informe o **preço** — sempre maior que zero. Esse é o valor que o studio recebe.
6. Marque quais profissionais realizam esse serviço.
7. Salve.

### Resultado esperado

O serviço passa a aparecer como opção no wizard de agendamento público, para os profissionais marcados.

**Ponto de atenção:** para pagamentos online, as taxas do gateway e do Gestify são somadas automaticamente para a cliente — o studio sempre recebe o valor cheio cadastrado aqui.
